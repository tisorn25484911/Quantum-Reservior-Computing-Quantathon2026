# PRODUCT_STRATEGY.md

Renewable-energy product track (designed, not executed; populated in Phase 12).
Reserved sections (spec §25):
1. Intake answers as testable claims: variable / horizon / decision fed / cost of
   error / incumbent (always name one) / data access / pre-registered success.
2. Potential users (solar, wind, hydro, storage, retail, grid, trading, ...).
3. Decisions that could benefit from ENSO/PDO/SOI forecasts.
4. ONE fully designed downstream experiment, arms A–E (no-index / true-index /
   persistence-index / classical-index / QRC-index), with the required
   operational dataset named + provenance + incremental-value metric.
5. Probabilistic outputs, feasibility metrics, and go/no-go Gates 1–7.

Note (spec §25.3): climate-index forecast accuracy alone is NOT a product; a
second-stage experiment linking predicted indices to an operational target is
required. That experiment is designed here, executed later.
