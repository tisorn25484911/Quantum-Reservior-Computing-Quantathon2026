# Quantum Reservoir Computing - Quantathon 2026

QRC main stack: the complete programme from exact NumPy reservoir to
product plan.

- **`QRC_code_stack/`** - the staged repository (stages 0-8: anchors,
  NumPy core, exact circuits, noise, Hamiltonian battery, qubit reuse,
  RF-QRC, integration, product plan). Stages 0-7 green under
  `run_tests.py`; see its `README.md` and `HANDOFF.md`.
- **`LaTeX_logbook/`** - the handbook (Parts I-XI) whose Parts IX-X
  specify the repository design; includes verified companion code and
  regenerated figures.
- **`.claude/skills/`** - project skills used to build and audit this
  work (QRC playbook, citation audit, arXiv retrieval, etc.).
