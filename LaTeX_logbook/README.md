# Quantum Reservoir Computing for Renewable Energy and Climate Prediction
## Research review and implementation handbook — source package

Build:  pdflatex main && bibtex main && pdflatex main && pdflatex main
        (TeX Live 2023+; no lmodern/T1 assumed — plain scalable CM fonts)

Layout:
  main.tex, frontmatter.tex, part1.tex ... part8.tex, references.bib
  figures/   all PDFs regenerated by code/eda.py and code/experiments.py
  code/      standalone Python programs (Python 3.12):
             qrc_core.py             exact reference reservoir + validation suite
             datasets.py             surrogate generators + real ENSO loader
             eda.py, experiments.py  all document figures and numbers
             cirq_qrc_minimal.py     Cirq restart-protocol example
             qiskit_qrc_hw.py        Qiskit hardware-aware pipeline + mid-circuit demo
             pennylane_qrc_hybrid.py PennyLane broadcast + differentiable tuning
             figstyle.py             shared figure style

Package versions used: numpy 2.4, cirq 1.7, qiskit 2.5 (+aer 0.17),
pennylane 0.45, statsmodels 0.14, pandas 3.0, scipy, matplotlib.
Every number in the document is printed by these scripts; run any file
directly (seconds to ~2 minutes each).
